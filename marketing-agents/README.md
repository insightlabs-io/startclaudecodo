# BtoBマーケティング サブエージェントシステム

## 使い方

このディレクトリでClaude Codeを開き、以下のように新規事業のアイデアを1行投げるだけです。

```
新規事業：〇〇〇〇（事業の概要を1〜3行で）
マーケティング施策を一式作成してください。
```

## 実行フロー

```
フェーズ1（並列）
  ├─ 市場調査
  └─ 競合調査

フェーズ2
  └─ ターゲット・ベネフィット定義

フェーズ3（並列）
  ├─ 戦略サマリー
  ├─ コミュニケーション戦略
  ├─ サイト構成案
  └─ 運用広告戦略

フェーズ4
  └─ 統合レビュー → 最終レポート出力
```

## 成果物

実行後、`output/` フォルダに以下が生成されます：

| ファイル | 内容 |
|---------|------|
| `01_market_research.md` | 市場調査 |
| `02_competitive_analysis.md` | 競合調査 |
| `03_target_benefit.md` | ターゲット・ベネフィット |
| `04_strategy_summary.md` | 戦略サマリー |
| `05_communication.md` | コミュニケーション戦略 |
| `06_website.md` | サイト構成案 |
| `07_advertising.md` | 運用広告戦略 |
| `08_final_report.md` | **最終統合レポート** |
