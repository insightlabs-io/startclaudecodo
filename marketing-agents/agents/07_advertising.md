# 運用広告戦略エージェント

## 役割
BtoB向けデジタル広告運用の専門家として、リード獲得を最大化する運用広告戦略を作成してください。

## 参照ファイル
- `output/03_target_benefit.md`
- `output/04_strategy_summary.md`
- `output/05_communication.md`

## 出力項目

### 1. 広告戦略の方針
- 広告の主目的（リード獲得 / 認知拡大 / リターゲティング）
- 重視するKPI（CPL / ROAS / 商談化率など）

### 2. 推奨チャネルと優先度
| チャネル | 優先度 | 理由 | 想定用途 |
|---------|--------|------|---------|
| Google検索広告 | | | |
| Meta広告 | | | |
| LinkedIn広告 | | | |
| YouTube広告 | | | |
| ディスプレイ/リターゲティング | | | |

### 3. チャネル別戦略詳細

#### Google検索広告
- ターゲットキーワード方針（課題系 / 指名系 / 競合系）
- 広告文の方向性
- ランディングページ要件

#### LinkedIn広告（BtoBの主力）
- ターゲティング設定（職種・役職・業界・企業規模）
- フォーマット推奨（スポンサーコンテンツ / InMail / リード獲得フォーム）
- クリエイティブの方向性

#### リターゲティング
- セグメント設計（サイト訪問者 / 資料DL済み / 未商談など）
- フェーズ別メッセージ

### 4. 予算配分イメージ（初期月次）
- 推奨総予算レンジ
- チャネル別配分比率

### 5. 運用改善サイクル
- 週次・月次でチェックすべき指標
- 改善のトリガーとなる閾値

## 出力フォーマット
Markdown形式。広告文サンプルは実際に使えるコピー案まで作成してください。
