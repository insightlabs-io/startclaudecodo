**作成日：** 2026年4月13日

## 1. トンマナ定義

### ブランドパーソナリティ（形容詞5つ）

| # | 形容詞 | 意味・ブランドへの反映 |
|---|--------|----------------------|
| 1 | **あたたかい** | 親の感情に寄り添い、「おめでとう」と一緒に喜んでくれる存在感 |
| 2 | **やさしい** | 難しい言葉・難しい操作を使わない。疲れた親でも迷わず使える |
| 3 | **誠実な** | 子どもの大切な記録を預かるサービスとして、過剰な演出よりも信頼を優先する |
| 4 | **ちょっとだけ特別な** | 日常の育児の中に「この瞬間はかけがえない」という感動を静かに添える |
| 5 | **一緒に喜ぶ** | ユーザーの達成感をアプリが増幅させる。サービスが「共感者」として振る舞う |

---

### 話し方のスタイル

**基本スタンス：** 親の隣で見守っている「頼れるお姉さん・お兄さん」のような語り口。専門家でも機械でもなく、育児を一緒に経験している存在。

| 項目 | 方針 | 例 |
|------|------|----|
| **文体** | です・ます調を基本とする。硬すぎず、フランクすぎない絶妙な距離感 | 「残せましたね。」「一緒に喜びましょう。」 |
| **人称** | 「あなた」は避け、子どもの名前や「赤ちゃん」を主語に使う | 「〇〇ちゃんが初めて笑いました」 |
| **句読点・改行** | 読みやすさ優先。短文を重ねてテンポを出す | 「大丈夫。ちゃんと残りました。」 |
| **感嘆符** | 多用しない。1文に1回まで、感動の場面に絞って使用 | 「初めての一歩、残りました！」 |
| **数字・データ** | 可能な限り具体的に。「すぐに」より「3秒で」 | 「3秒でできた記録が、一生残ります。」 |
| **記念・祝福表現** | シンプルで自然なお祝い言葉を使う | 「おめでとうございます。」「すばらしい瞬間ですね。」 |

---

### 避けるべき表現・トーン

| カテゴリ | 避けるべきこと | 理由 |
|---------|--------------|------|
| **煽り・恐怖訴求** | 「今すぐ記録しないと後悔します！」「見逃したら取り戻せない」 | 育児中の親の不安を過剰に刺激する。ブランド毀損につながる |
| **過剰なポジティブ** | 「最高！」「完璧！」「パーフェクト！」 | 疲弊した育児ママ・パパには空虚に響く |
| **上から目線** | 「正しい記録の方法」「育児の専門家が推奨」 | 育児に自信を持てない親の自己肯定感を傷つける |
| **機能説明の羅列** | 「高性能AI搭載」「クラウドバックアップ機能」 | 育児中の親は機能よりも感情体験を求めている |
| **ジェンダー偏重** | 「ママのための」「パパも使える」 | パパユーザーへの訴求を阻害する。中立的な表現を使う |
| **急かす表現** | 「今だけ」「期間限定」（インストール訴求の乱用） | ブランドの「あたたかさ」と矛盾する |
| **過度な赤ちゃん言葉** | 「いっぱいにこにこ♡」 | 信頼感・誠実さを損なう |

## 2. メッセージアーキテクチャ

### コアメッセージ（全チャネル共通の核心）

> **「"初めて"は、一度しかない。だから、ちゃんと残そう。」**

このコアメッセージは以下の3層構造で支えられている：

```
┌─────────────────────────────────────────────────────────────┐
│  コアメッセージ（感情の核）                                   │
│  "初めて"は、一度しかない。だから、ちゃんと残そう。          │
├─────────────────────────────────────────────────────────────┤
│  機能ベネフィット（理性的根拠）                               │
│  →忙しい親でも確実に残せる、マイルストーン特化の記録アプリ   │
├─────────────────────────────────────────────────────────────┤
│  情緒ベネフィット（感情的価値）                               │
│  →子どもが大きくなったとき、一緒に開く成長の贈り物に         │
└─────────────────────────────────────────────────────────────┘
```

## 4. SNS・コンテンツテーマ案（月次運用想定）

月に1〜2本ずつ計画的に配信。共感・教育・口コミの3種を均等に回す運用設計。

---

### 共感系コンテンツテーマ（3案）

**テーマ1：「あのとき逃した瞬間」あるある**

> 育児中の親なら誰もが感じる「撮れなかった後悔」を共感コンテンツに転換。

- コピー案：「写真を撮ろうとしたら、もう終わってた。#育児あるある #初めての瞬間 #できた」
- 形式：縦型動画（Reels/TikTok）、ママの等身大なエピソードをモノローグ風に語る
- 狙い：共感によるシェア・保存・フォロワー増加

**テーマ2：「ちゃんとした親でいたい」が揺れる瞬間**

> 育児の不安や自己肯定感の揺れを正直に描く。「それでいい」と伝えるコンテンツ。

- コピー案：「今日、記録できなかった。でもそれより、一緒にいたことの方が大事だったな。#育児中 #等身大の育児 #できた」
- 形式：テキスト投稿＋やわらかい写真素材（Instagramフィード）
- 狙い：ブランドへの信頼醸成・フォロワーとの関係性構築

**テーマ3：「成長の速さへの驚きと切なさ」**

> 赤ちゃんの成長が早すぎるという感情を、美しいビジュアルで描く。

- コピー案：「生後7日と生後7ヶ月。こんなに変わった。#あっという間 #記録しててよかった #できた」
- 形式：Before→Afterの2枚並べ（Instagramフィード・ストーリーズ）
- 狙い：「自分もやりたい」というインスピレーション→ダウンロード誘導

---

### 教育系コンテンツテーマ（3案）

**テーマ4：「月齢ごとのマイルストーン一覧」シリーズ**

> 「生後〇ヶ月のうちに撮っておきたい瞬間5選」という実用コンテンツ。

- コピー案：「生後3ヶ月、まだ間に合う"初めて"5つ。記録しましたか？ #生後3ヶ月 #育児記録 #できた」
- 形式：インフォグラフィック（カルーセル投稿）
- 狙い：ターゲット月齢の親への検索流入・保存数増加

**テーマ5：「育児記録を続けるための3つのコツ」**

> 記録が続かない悩みに直接応える情報系コンテンツ。

- コピー案：「記録が続かないのは意志の問題じゃない。仕組みが大事。#育児ハック #続ける育児記録 #できた」
- 形式：テキスト多めのカルーセル（Instagram・X）
- 狙い：「役に立つ」という印象でブランド好意度向上

**テーマ6：「おじいちゃん・おばあちゃんへの共有ガイド」**

> 祖父母世代との共有機能の使い方を、親切に解説するコンテンツ。

- コピー案：「スマホが苦手なおばあちゃんも、これならひとりで見られます。設定5分で完了。 #おじいちゃんおばあちゃん #孫の成長 #できた」
- 形式：スクリーンショット＋矢印解説（カルーセル）
- 狙い：機能理解の促進・既存ユーザーの「共有数」増加→家族への伝播

---

### 口コミ促進コンテンツテーマ（3案）

**テーマ7：「ユーザーストーリー」シリーズ**

> 実際のユーザー体験（UGC活用）を丁寧に紹介。許可を取った上で投稿写真・エピソードをリポスト。

- コピー案：「"夫が涙ぐんで記録してくれました"（Yさん・31歳・ママ） #ユーザーの声 #できた体験談」
- 形式：引用カード型投稿（統一テンプレート）
- 狙い：社会的証明・共感によるダウンロード誘導

**テーマ8：「#できた記録」ハッシュタグキャンペーン**

> 親が子どもの「初めての瞬間」を投稿するキャンペーンを定期開催。

- コピー案：「あなたのお子さんの"初めて"を教えてください。#できた記録 に投稿すると、公式がご紹介するかもしれません。」
- 形式：キャンペーン告知投稿＋UGCリポスト
- 狙い：ブランド認知の拡大・ユーザーコミュニティ形成

**テーマ9：「パパが使った感想」特集**

> 男性ユーザーのリアルな使用感を発信し、パパペルソナへのリーチと口コミを促進。

- コピー案：「育休中、毎日記録していた。仕事に戻った今、あの時間が財産になっている。（Kさん・34歳・パパ）」
- 形式：縦型インタビュー動画（Reels・TikTok）
- 狙い：パパユーザー層の獲得・夫婦共有利用率の向上

## 5. チャネル別メッセージ最適化ガイド

| チャネル | トーン調整 | 重点メッセージ | 注意点 |
|---------|----------|--------------|-------|
| **Instagram（フィード）** | 感情重視・視覚的に美しく | 「感動体験」「かけがえない瞬間」 | 文字少なめ、高品質な赤ちゃん写真必須 |
| **Instagram（ストーリーズ）** | テンポ感・インタラクティブ | 「今日の〇〇はできましたか？」 | スワイプアップCTA、ポールで共感促進 |
| **TikTok** | 親しみやすい・リアル・ユーモア | 「育児あるある」の共感 | 編集重めより等身大感。1本目5秒でフック |
| **X（旧Twitter）** | 共感・テキスト強め | 「後悔したくない育児記録」 | ハッシュタグ最大2つ。リプライでコミュニティ醸成 |
| **App Store説明文** | 明確・機能ベネフィット重視 | 「何ができるか」を具体的に | キーワード最適化（初めて・マイルストーン・成長記録） |
| **産院・小児科配布物** | 信頼感・シンプル・温かい | 「大切な"初めて"を残しましょう」 | QRコード必須。文字は最小限 |
| **プッシュ通知** | 短く・タイムリー・感情的 | 「〇〇ちゃんの1ヶ月記念日です」 | 1日1通まで。ユーザーのライフサイクルに連動 |

- 「〇〇ちゃん、生後3ヶ月です。そろそろ初めての寝返りかもしれません。」

- 「今週の"できた"を振り返ってみましょう。」

> 赤ちゃんの「初めての笑顔」「初めてのハイハイ」「初めての言葉」——1歳になるまでに、あなたのお子さんには約50の"初めて"が訪れます。「できた」は、その瞬間を写真・動画・ひとことと一緒に確実に残すためのマイルストーン記録アプリです。忙しい育児中でも、片手で3秒で記録完了。夫婦でリアルタイム共有、遠方の祖父母への閲覧リンク発行も可能。子どもが大きくなったとき、一緒に開く成長の贈り物を、今日から作り始めましょう。
