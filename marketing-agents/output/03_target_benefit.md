## 1. ターゲットユーザー像（Demographics）

### 年齢・家族構成

| 項目 | 詳細 |
|------|------|
| **年齢層** | 25〜35歳（育児世代のコア層） |
| **家族構成** | 乳幼児を持つ2人親世帯（核家族）が主軸。遠方に祖父母がいるケースが多い |
| **配偶者** | 共働き夫婦が多数。パパの育児参加率が高まっている層 |
| **子どもの数** | 第一子が最優先ターゲット。1人の子どもへの感情的投資が最も大きい層 |

### 子どもの年齢層

| 優先度 | 子どもの月齢・年齢 | 理由 |
|--------|-------------------|------|
| **最優先** | 0〜12ヶ月（乳児期） | 「初めて笑った」「初めて立った」などのマイルストーンが最も集中する時期。記録意欲が最高潮 |
| **高** | 1〜2歳（よちよち期） | 「初めて歩いた」「初めてしゃべった」など言語・運動の発達マイルストーンが続く |
| **中** | 2〜3歳（自我・言語爆発期） | マイルストーンは継続するが記録頻度が落ちやすい時期。リテンション施策が必要 |

### ライフスタイル・デジタルリテラシー

| 特性 | 詳細 |
|------|------|
| **スマートフォン利用** | 育児世代（25〜35歳）の所持率98%超。写真・動画での記録が日常習慣 |
| **SNS利用** | Instagram・TikTok・Xを日常的に使用。育児コンテンツの発信・消費に積極的 |
| **情報収集** | 育児アプリ・InstagramのハッシュタグからSNS・ママ友口コミ・産院紹介まで多様なチャネルを活用 |
| **時間的制約** | 睡眠不足・時間不足が慢性的。新しいアプリの学習コストに非常に敏感 |
| **アプリ利用経験** | 育児アプリ利用経験者率60〜70%。「ぴよログ」「みてね」などの利用経験がある層も多い |
| **購買意欲** | 1人の子どもへの感情的・経済的投資が高く、月額300〜500円程度の課金ハードルは低い |

## 2. ペルソナ（優先度順）

---

### ペルソナ1（最優先）：はじめての育児に全力投球するママ

```
┌─────────────────────────────────────────────────────────┐
│  名前：田中 さくら（仮名）                               │
│  年齢：29歳                                             │
│  職業：育児休業中（元会社員・マーケティング職）          │
│  家族：夫（31歳・会社員）＋第一子（生後4ヶ月・女の子）   │
│  居住：東京都内の2LDKマンション。実家は新幹線距離の地方  │
└─────────────────────────────────────────────────────────┘

【抱えている感情・不安・期待】
- 「娘の初めての笑顔を見た瞬間、スマホを取りに行ったら終わっていた」という後悔が忘れられない
- Instagramでは育児を発信しているが、「子どもが大きくなったときに渡せるちゃんとした記録」を残せていない不安がある
- 「ぴよログ」で授乳記録はつけているが、感動した瞬間を書き留める場所がない
- 遠方の義母・実母に孫の成長を見せたいが、LINEへの手動転送が面倒
- 「ちゃんとした親」でいられているか、育児への不安と自己肯定感の揺れが大きい

【情報収集行動】
- Instagram（#生後4ヶ月 #ワンオペ育児 #育児記録）を毎日チェック
- ママ友グループのLINEで育児アプリや離乳食情報を交換
- 産院でもらった育児冊子・助産師からの口コミ
- YouTube「育児vlog」を子どもが寝てから視聴

【アプリに求めること】
- 直感的に使えてすぐに記録できる（手が離せない状況でも片手で操作）
- 「初めての笑顔」「初めてのハイハイ」を写真・動画と一緒に記念として残せる
- 記録を実家の両親・義両親にワンタップで共有できる
- アプリ自体が「おめでとう」と言ってくれるような感動的な体験
- 子どもが大きくなったときに一緒に見返せる形で保存されている安心感
```

### ペルソナ2（高優先）：育休を取って本気で育児に参加するパパ

```
┌─────────────────────────────────────────────────────────┐
│  名前：鈴木 健太（仮名）                                │
│  年齢：32歳                                             │
│  職業：IT企業エンジニア（育児休業中・3ヶ月取得）         │
│  家族：妻（30歳・看護師）＋第一子（生後2ヶ月・男の子）   │
│  居住：神奈川県。お互いの実家は関東内だが電車で1時間以上  │
└─────────────────────────────────────────────────────────┘

【抱えている感情・不安・期待】
- 育休を取ったのに「妻の方が育児が上手い」という劣等感があり、自分が何かできることを探している
- 子どもの成長を自分なりに記録・残したいが、既存の育児アプリは「ママ向け」な雰囲気があって使いにくいと感じる
- 「俺が記録した初めての〇〇」を形にして残せたら嬉しい、という父親としての達成感への期待
- 育休終了後も子どもの成長から置いていかれたくない焦り
- エンジニアとして、プライバシー・セキュリティへの意識が高くクラウドへの写真アップに慎重

【情報収集行動】
- X（旧Twitter）で育児体験談・パパブログを検索
- Podcastで育児・教育系コンテンツを聴く
- AppStoreのレビューを丁寧に読んで比較検討する
- 会社の先輩パパ・育休同期との情報交換

【アプリに求めること】
- 夫婦で同時に記録・共有できる共同機能（誰が記録したかが分かる）
- スッキリしたUI・男性も使いやすいデザイン
- 「パパが最初に記録した瞬間」が特別扱いされるような体験
- プライバシーが守られているという明確な安心感
- エクスポート・データ移行が自由で「このサービスに縛られない」安心感
```

### ペルソナ3（中優先）：記録は残したいが忙しくて続かない二人目ママ

```
┌─────────────────────────────────────────────────────────┐
│  名前：山本 あかり（仮名）                              │
│  年齢：34歳                                             │
│  職業：時短勤務（元フルタイム・総合職）                 │
│  家族：夫（36歳）＋長女（3歳）＋第二子（生後7ヶ月）     │
│  居住：大阪市内。実母が近隣在住でサポートあり           │
└─────────────────────────────────────────────────────────┘

【抱えている感情・不安・期待】
- 第一子のときは育児日記もアプリも続けたが、二人目は上の子の世話との並行で記録がほぼできていない罪悪感
- 「上の子のときはこんなだったっけ？」と比較したくなるが、第一子の記録も整理できていなくて探せない
- 時間がないので「自動でやってくれる」ならお金を払ってもいい
- 第二子が成長してから「ちゃんと記録してあげられなかった」と後悔したくない
- 近くに住む実母が「スマホで孫の様子を毎日見たい」とせがんでくる

【情報収集行動】
- 時間がないため、SNSよりも口コミサイト（ママリ・ウィメンズパーク）でのレビューを参考にする
- 保育園・ママ友からのリアルな口コミが最も信頼できる情報源
- AppStoreの「おすすめアプリ」から発見することも多い

【アプリに求めること】
- とにかく記録が「ラク」「速い」「続けられる」こと（入力ステップが極限まで少ない）
- AIやカメラロール連携で「自動的に記録候補を提案」してほしい
- 第一子・第二子を並行して管理できる複数人対応
- 近くに住む母（祖父母世代）が操作できるシンプルな共有機能
- 記録を振り返るときに「ちゃんと育ててきた」という自己肯定感を得られる体験
```

## 3. 機能ベネフィット

### アプリが直接解決する課題

| 課題（ペインポイント） | 「できた」の解決策 |
|----------------------|-------------------|
| **「初めての瞬間」を逃す恐怖（PP1）** | マイルストーン特化のワンタップ記録UI。写真・動画と日付・ひとことをセットで即時保存。月齢に応じた「そろそろ〇〇かも」通知で事前に準備できる |
| **記録が続かない（PP5）** | 入力ステップを最小化した超シンプルUI。AIによるカメラロール解析で「これ初めて笑ってる？」と自動候補を提案。記録のハードルをゼロに近づける |
| **写真・動画が分散して探せない（PP2）** | 「初めての〇〇」カテゴリで構造化されたマイルストーム図鑑。時系列ではなく「できたこと」として整理されるため、いつでも一瞬で探せる |
| **家族間の共有が面倒（PP3）** | 夫婦の共同記録リアルタイム同期。祖父母向けのシンプル閲覧専用リンクで、LINEへの手動転送が不要になる |
| **記録を見返せる形にできていない（PP4）** | 月ごとの自動まとめ動画生成。「◯ヶ月のできた」を自動スライドショーで生成し、後から感動的に振り返れる |

### 使うことで得られる具体的な成果

- 赤ちゃんのマイルストーム（初めての笑顔・初めてのハイハイ・初めての言葉）が写真・動画と日付入りで確実に残る
- 記録の継続率が上がり、「気づいたら1年分の成長が揃っていた」という体験を得られる
- 夫婦で同じ記録を共有できることで、育児参加の実感と達成感が両者に生まれる
- 遠方の祖父母がリアルタイムで孫の成長を見られ、「連絡を頼まれるストレス」が軽減される
- 子どもが成長した後に「あの頃の記録」を一冊の本のように振り返れる資産が手元に残る

## 4. 情緒・体験ベネフィット

### ユーザーが個人として得られる感情的価値

| 感情的価値 | 詳細 |
|-----------|------|
| **「ちゃんとした親」でいられている安心感** | 忙しくても記録が残せていることが、親としての自己肯定感を支える |
| **後悔しないという解放感** | 「あの瞬間を残せなかった」という育児最大の後悔をなくす。「これで大丈夫」という心の余裕 |
| **子どもの成長を共に喜ぶ達成感** | 「できた！」の瞬間をアプリが一緒に祝ってくれることで、親自身の達成感と喜びが増幅される |
| **育児を「記録する価値あるもの」として再定義** | 日常の育児が「かけがえのない物語」に変わるという感覚。記録行為そのものが意味を持つ |
| **「子どもへの贈り物を作っている」という充実感** | 今記録していることが将来子ども本人に渡せるタイムカプセルになるという長期的な意義 |

### 家族として得られる体験価値

| 体験価値 | 詳細 |
|---------|------|
| **夫婦で育児を共有する一体感** | パパとママが同じアプリで同じ記録をリアルタイムで見られることで、育児の「共同作業感」が生まれる |
| **離れた家族をつなぐ絆** | 遠方の祖父母が孫の「初めての瞬間」を同時に喜べる。家族全員で育てている実感を共有できる |
| **子どもへのプレゼントを一緒に作る体験** | 親子・家族で「できた図鑑」を一緒に見返す時間が、新しい家族のルーティンになる |
| **家族の歴史が積み重なる安心感** | 赤ちゃんの時期が終わっても消えない「家族のデジタル遺産」として残り続ける価値 |

## 5. バリュープロポジション（1文）

---

> **「赤ちゃんの"初めて"を、忙しい親でも確実に残せる——子どもが大きくなったとき、一緒に開く成長の贈り物に。」**

---

### 補足解説

このバリュープロポジションは以下の3要素を凝縮している：

1. **ターゲット：** 忙しくても我が子の成長を記録したいと願うすべての親（特に第一子を持つ25〜35歳のパパ・ママ）
2. **機能ベネフィット：** 初めての瞬間を確実に・手軽に記録できること（継続できる仕組み）
3. **情緒ベネフィット：** 記録が子どもへのタイムカプセル・贈り物になるという長期的な感情的価値

競合（みてね・ぴよログ）が「保管する」「管理する」というメッセージに寄っている中、「できた」は**記録の目的を「子どもへの贈り物を作ること」に再定義**し、感情的な共鳴を最大化するポジションを取る。

## 6. ターゲット・ベネフィットの優先度マトリクス

```
感情的インパクト
高 │  [ペルソナ1：はじめてのママ]  [ペルソナ2：育休パパ]
   │      ↑最優先獲得ターゲット
   │
   │
低 │                              [ペルソナ3：二人目ママ]
   │                               ↑継続・拡大フェーズで獲得
   +────────────────────────────────────────
      獲得難易度：高                獲得難易度：低
```

**最優先アクション：**
第一子を持つ産後0〜6ヶ月の親（パパ含む）を最優先ターゲットとして設定。産院・小児科チャネルでの初期接触と、「初めての〇〇」マイルストーン特化UIで、既存アプリが満たせていない「感動体験」というポジションを確立する。
