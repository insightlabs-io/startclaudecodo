### カテゴリ別整理

#### 直接競合（同じ課題を同じ方法で解く）
赤ちゃん・子どもの成長を記録・保存・共有することをスマートフォンアプリで実現するサービス群。「できた」と最もユーザーを取り合う可能性が高い。

#### 間接競合（同じ課題を別の方法で解く）
「思い出を残して家族と共有したい」という根本ニーズには応えるが、成長記録に特化していない汎用ツール。手軽に使える反面、構造化・検索・振り返りの機能は弱い。

#### 代替手段（アプリではなく現状の対処法）
デジタルツールを使わずに課題に対処している層。アプリへの移行コストや習慣の壁があるが、潜在市場として存在する。

## 2. 主要競合の特徴分析

### 競合① みてね（Family Album）

**サービス概要：** mixi（現MIXI）が運営する家族向け写真・動画共有アプリ。国内最大手で2,000万家族以上が利用。

| 項目 | 内容 |
|---|---|
| **強み** | 国内最大のユーザー基盤と認知度、容量無制限の写真・動画保存、祖父母も使いやすいシンプルなUI、フォトブック・DVDなどの有料サービスとの連携、「○年前の今日」などの振り返り機能 |
| **弱み** | 「初めてできたこと」に特化した記録機能が弱い（マイルストーン管理が主目的でない）、投稿が時系列の写真ストリーム中心で検索・分類が不十分、成長指標や発達チェックリストがない、コメント・反応機能が限定的 |
| **ターゲット** | 0〜6歳の子を持つ親（特に母親）、祖父母世代も含む家族全体 |
| **価格・ビジネスモデル** | 基本無料（写真・動画の保存・共有）、プレミアムプラン月480円〜（動画の高画質保存など）、フォトブック・DVD作成などのグッズ販売 |
| **メッセージング** | 「家族みんなでわが子の成長を見守る」「離れた祖父母にも届けたい」という家族のつながりを前面に打ち出す |
| **ポジショニング** | 家族共有プラットフォームのスタンダード。育児の「記録ツール」というよりも「家族SNS」に近い立ち位置 |

---

### 競合② ぴよログ

**サービス概要：** 授乳・ミルク・おむつ・睡眠・体温などの育児記録を時系列で管理できるアプリ。主に乳幼児期（0〜2歳）向け。

| 項目 | 内容 |
|---|---|
| **強み** | 授乳・睡眠など日常ケアの記録に特化した高い精度、タイマー機能や入力のしやすさ、夫婦2人での共同記録・リアルタイム同期、グラフによるデータ可視化、小児科への持参にも使えるデータ管理 |
| **弱み** | 「初めてできたこと」という感情的・思い出的な記録には不向き、写真・動画の保存・共有機能が限定的、成長の節目をストーリーとして振り返る体験がない、デザインが実用的すぎて情緒的な訴求力が低い |
| **ターゲット** | 新生児〜1歳前後の子を持つ親（特に第一子の親）、育児の管理・効率化を求めるユーザー |
| **価格・ビジネスモデル** | 基本無料、プレミアムプラン月300円（複数デバイス同期・広告非表示など） |
| **メッセージング** | 「育児を記録して、育てやすくする」という実用性・効率性を前面に打ち出す |
| **ポジショニング** | 育児管理ツールとしての実用的な立ち位置。家事・育児の「タスク管理」寄りのアプリ |

---

### 競合③ Tinybeans

**サービス概要：** オーストラリア発・現在はグローバルで展開する子ども成長記録アプリ。日々の写真投稿と成長マイルストーン管理が特徴。

| 項目 | 内容 |
|---|---|
| **強み** | マイルストーン記録機能が充実（初めて歩いた・話したなどをタグ付け可能）、カレンダー形式の振り返りUIが優れている、家族を招待して共有できるクローズドSNS設計、「おめでとう」などの反応機能、英語圏での高い認知度 |
| **弱み** | 日本語対応が限定的でUI・サポートが英語中心、日本市場での認知度・普及率が低い、日本の育児文化（母子手帳・予防接種管理など）との連携がない、国内決済・サポート体制が弱い |
| **ターゲット** | グローバルには0〜5歳の子を持つ親（英語圏が主流）、日本では帰国子女・国際感覚のある親層 |
| **価格・ビジネスモデル** | 基本無料、Tinybeans+（プレミアム）月$4.99〜（広告非表示・追加ストレージなど） |
| **メッセージング** | 「Every tiny moment matters（小さな瞬間がすべて大切）」子どもの成長の一瞬一瞬を大切にというコンセプト |
| **ポジショニング** | 成長マイルストーン特化の記録アプリとして「できた」に最も近いコンセプトを持つ競合 |

## 3. 競合の共通の弱点

### どの競合も解決できていない課題

| # | 課題 | 詳細 |
|---|---|---|
| 1 | **「初めて」という特別な瞬間への特化度の低さ** | みてね・ぴよログは日常記録が中心で、「初めてできたこと」を体験として切り取る設計になっていない。Tinybeansは近いが日本市場での普及率が低い |
| 2 | **感情的・物語的な振り返り体験の欠如** | 写真ストリームや時系列ログでの記録はできるが、「赤ちゃんの成長の物語」として感動的に振り返れるUXがない |
| 3 | **発達の「見通し」との連携不足** | 「今次は何ができるようになるか」という発達段階の情報や、次のマイルストーンへの期待感を育てる機能がない |
| 4 | **パパの参加率の低さへの対策** | ほとんどのアプリが母親メインで設計されており、父親が積極的に記録・共有したくなる動線がない |
| 5 | **記録の継続性の低下** | 新生児期は熱心に記録するが、生後半年〜1年で記録頻度が急減する問題。継続を促す仕組みが不十分 |
| 6 | **子ども本人が将来見られる設計** | 記録は「親のため」に閉じており、子どもが成長してから自分の歴史として見返せるコンセプトが弱い |

### ユーザーから不満が出やすいポイント（主要競合共通）

- **検索・分類の不便さ：** 大量の写真・記録の中から「特定のできごと」を探し出しにくい
- **整理の手間：** 記録はできても、後から見やすく整理・編集する機能が弱い
- **容量・データ移行の不安：** サービス終了時のデータ保全や他サービスへの移行手段が不明確
- **通知・リマインドの過多または不足：** 記録を促す通知が煩わしい、または忘れてしまう
- **パートナーとの温度差：** 片方が熱心で片方が無関心、共同記録がうまく機能しない
- **プライバシーへの不安：** 子どもの顔写真をクラウドに上げることへの漠然とした不安

## 4. 差別化の余地

### 参入余地のあるポジション

| ポジション | 概要 | 実現可能性 |
|---|---|---|
| **「初めて」の瞬間に特化した感動体験** | 日常記録ではなく「節目の瞬間」だけを美しく残すことに絞ったUX。写真一枚に添えるひとことと日付がメインで、シンプルかつ感情的な訴求力が高い | 高 |
| **発達ガイドと連携した「次のできた」予告** | 月齢に応じた発達の見通し情報を組み合わせ、「そろそろ〇〇できるかも！」と親の期待感を高め、記録のモチベーションを維持させる | 高 |
| **「子どもへのタイムカプセル」コンセプト** | 記録は子どもが18歳になったときに渡す贈り物という設計。親の気持ち・メッセージも一緒に残せる。競合にない感情的な差別化軸 | 高 |
| **パパ参加設計** | 父親が参加しやすいUI・通知・ゲーミフィケーション（「パパが記録した初めて」バッジなど）を設計し、両親で育てる体験を強化 | 中 |
| **オフライン・プライバシーファースト** | ローカル保存・エンドツーエンド暗号化など、子どもの写真をクラウドに上げたくない層に特化したプライバシー重視設計 | 中 |

### 競合が取りにくい強みの方向性

#### 方向性A：「感動の再現性」を高める
大手（みてね）は写真・動画の保管・共有がコアのため、「感動体験のデザイン」に経営資源を割きにくい。「できた」は記録のUIそのものに感情設計を組み込むことで差別化できる。

具体例：
- 記録した瞬間に「おめでとう」アニメーション・効果音
- 月ごと・年ごとに「今月のできた」を自動でまとめた動画/スライドショー生成
- 親へのインタビュー形式（「そのとき何を感じましたか？」）でテキストも残す設計

#### 方向性B：「発達の見通し×記録」の統合
ぴよログは記録ツール、育児書・発達情報は別で調べるという分断がある。記録に発達ガイドを紐付けることで「この記録がいかに重要な節目か」を可視化し、記録の価値を高める。

具体例：
- 「初めて立った」を記録すると「平均より2週間早い！」などの発達情報が表示される
- 次に来るマイルストーンへのカウントダウン機能
- 発達の心配事があった場合のソフトランディング（専門家Q&Aへの導線）

#### 方向性C：「家族の外側」への共有設計
競合はいずれも「家族内クローズド」または「SNS公開」の二択。祖父母へのシェアを「家族限定SNS」ではなく、絵本・フォトカード・動画レターなどのリアルなアウトプットと連携させることで、デジタルとアナログを橋渡しするユニークなポジションを取れる。

具体例：
- 記録を元に「成長絵本」を自動生成・印刷注文できる機能
- 「ひいおじいちゃんへのビデオレター」をLINEやSMSで送れる祖父母向け特別UI
- 誕生日・ハーフバースデーに自動でベストショット動画を生成

## まとめ：「できた」の競合優位性の方向性

**推奨ポジショニング：**
> 「赤ちゃんの成長の"節目"を、感動として残し、子どもへの贈り物にする」

- **みてね** との差別化：日常記録の量ではなく、節目の質と感動体験
- **ぴよログ** との差別化：実用的な管理ではなく、感情的・記念的な記録
- **Tinybeans** との差別化：日本市場・日本の育児文化へのローカライズと、タイムカプセルコンセプト

競合が「記録を保管する」ことに注力している中、「できた」は**記録を通じて親子の絆を育て、子どもへの贈り物を作る**という独自の価値軸で参入余地がある。
