# 市場調査レポート：赤ちゃんの成長記録アプリ「できた」

**調査日：** 2026年4月13日
**対象事業：** 赤ちゃんの初めてできたことを記録するアプリ「できた」

---

## 1. 市場概況

### 対象市場の定義と規模感（TAM / SAM / SOM）

#### TAM（Total Addressable Market）：到達可能な最大市場）
- **定義：** スマートフォンを所持する全世界の乳幼児を持つ親
- **規模感：**
  - 日本国内の年間出生数：約70万人（2025年時点）
  - 乳幼児（0〜3歳）の保護者人口：推定約200万世帯
  - 育児アプリ市場（国内）：約300〜400億円規模と推定
  - グローバル育児テックアプリ市場：約1,500億〜2,000億円規模（年率8〜10%成長）

#### SAM（Serviceable Available Market）：実際にサービス提供できる市場）
- **定義：** スマートフォンを日常的に使用し、デジタルで育児記録を残すことに関心を持つ国内の親（0〜2歳の乳幼児を持つ親）
- **規模感：**
  - 0〜2歳の子を持つ国内世帯：推定約100〜120万世帯
  - 育児アプリ利用経験者率：60〜70%（育児日記・成長記録アプリ利用調査より）
  - SAM推定：約70〜80万世帯
  - 有料化率を仮定（月額500円）した市場規模：約40〜50億円/年

#### SOM（Serviceable Obtainable Market）：現実的に獲得可能な市場）
- **定義：** ローンチ後3年以内に獲得を目指すユーザー層（アーリーアダプター〜アーリーマジョリティ）
- **規模感：**
  - 目標シェア：SAMの5〜10%
  - SOM推定：約3.5〜8万世帯
  - 収益試算（月額300〜500円の有料プレミアム、課金率15%仮定）：年間約1.9〜7.2億円

### 市場の成長トレンドと背景

| トレンド | 内容 |
|----------|------|
| 育児DXの加速 | 母子手帳のデジタル化が自治体主導で推進。2025年時点で全国約200以上の自治体がデジタル母子手帳に移行または試験導入 |
| スマートフォン育児の日常化 | 育児世代（25〜35歳）のスマートフォン所持率は98%超。写真・動画での記録が当たり前化 |
| 少子化と「特別体験化」 | 1世帯あたりの子どもの人数が減少し、1人の子どもにかける時間・お金・思い出への投資が増加。「かけがえのない瞬間を残す」価値が高まっている |
| 育児アプリ市場の拡大 | 国内育児アプリのダウンロード数は2020年以降、年率10〜15%成長。「子育てハピネス」「ぴよログ」などが百万DL超を達成 |
| パパの育児参加増加 | 育児休業取得率の男性側向上（2024年時点で約30%超）により、父親もアプリを通じた育児記録に参加する需要が増加 |

## 2. ユーザーの課題構造

### 子育て中の親が抱えるペインポイント（上位5つ）

#### ペインポイント1：成長の瞬間を見逃す・記録できない恐怖
- **内容：** 初めて笑った瞬間、初めて立った瞬間など「一度しかない」出来事を見逃す、もしくはカメラを準備する前に終わってしまう
- **深刻度：** ★★★★★（非常に高い）
- **緊急度：** ★★★★☆（高い）
- **背景：** 子どもの発達は突発的かつ一瞬。後悔しやすく、感情的な痛みを伴う

#### ペインポイント2：写真・動画が分散しており整理できない
- **内容：** スマートフォン本体・クラウド・LINEアルバム・Instagramなどに子どもの写真・動画が散乱し、「あの瞬間の写真どこに保存したっけ？」と探せない
- **深刻度：** ★★★★☆（高い）
- **緊急度：** ★★★☆☆（中程度）
- **背景：** 育児世代の親は1ヶ月に数百枚の写真を撮影。整理に割く時間と精神的余裕がない

#### ペインポイント3：夫婦・祖父母など家族間での記録共有が面倒
- **内容：** パパ・ママで別々に記録しており、お互いが「どこまで記録したか」を把握できない。祖父母に共有するのもLINEで都度手動転送が必要で手間がかかる
- **深刻度：** ★★★★☆（高い）
- **緊急度：** ★★★★☆（高い）
- **背景：** 核家族化・共働き化が進む中で、離れた祖父母も子どもの成長をリアルタイムで見たいというニーズが高まっている

#### ペインポイント4：成長の記録を見返せる形にできていない
- **内容：** 大量の写真・動画を撮っていても、後から「○ヶ月のあの頃」「初めての○○」をまとめて見返せる形になっていない
- **深刻度：** ★★★☆☆（中程度）
- **緊急度：** ★★☆☆☆（低め）
- **背景：** 記録はしているが整理・可視化できていないギャップ。子どもが大きくなった後に後悔するケースが多い

#### ペインポイント5：育児記録の継続が難しい
- **内容：** 育児日記や成長記録を始めてもすぐに記録が滞る。手書き日記はハードルが高く、アプリも操作が複雑だと続かない
- **深刻度：** ★★★★☆（高い）
- **緊急度：** ★★★★★（非常に高い）
- **背景：** 子育て中の親は睡眠不足・時間不足の状態が慢性的。記録作業が「もう一つのタスク」になると離脱する

---

### 課題の深刻度・緊急度マトリクス

```
緊急度
高 |  [PP1:見逃す恐怖]  [PP5:継続困難]
   |
   |  [PP3:家族共有]
   |
低 |  [PP2:写真散乱]   [PP4:見返せない]
   +------------------------------------------
      深刻度：低              深刻度：高
```

**最優先対応領域：PP1（見逃す恐怖）とPP5（継続困難）**
この2つは感情的インパクトが最大であり、アプリの中核価値設計に直結する。

## 3. 市場環境分析

### 追い風となるマクロトレンド（技術・社会変化・育児トレンド）

#### 技術トレンド

| トレンド | アプリへの影響 |
|----------|---------------|
| スマートフォンカメラの高性能化 | 手軽に高品質な動画・写真の撮影が可能になり、記録行動のハードルが低下 |
| クラウドストレージの普及・低価格化 | 大量の写真・動画をコスト低く保存できる基盤が整備済み |
| AIによる自動タグ付け・分類技術 | 「笑った瞬間を自動検出」「初めて立った動作を認識」などのAI活用で、記録の手間を極小化できる |
| プッシュ通知・ウィジェット技術 | 記録のリマインダーをさりげなく通知し、継続率を向上させる手段が充実 |
| 家族間リアルタイム共有基盤 | Firebase等のリアルタイムDB技術により、家族全員がほぼ同時に更新内容を確認できる |

#### 社会変化トレンド

| トレンド | アプリへの影響 |
|----------|---------------|
| 少子化による「1人の子への価値集中」 | 1人の子どもの成長記録に対する感情的・経済的投資が拡大 |
| 共働き・核家族化の進行 | 遠方の祖父母と子どもの成長をデジタルでつなぐ需要が増加 |
| パパの育児参加率向上 | 育休取得率上昇により、父親も育児記録ユーザーとして取り込める |
| SNS利用の多様化 | Instagramへの直接共有機能など、SNS連携がユーザー獲得の入口になりうる |
| デジタル遺産・思い出保存意識の高まり | 成長記録をデジタル資産として長期保存・承継するニーズが顕在化 |

#### 育児トレンド

| トレンド | アプリへの影響 |
|----------|---------------|
| マイルストーン育児の浸透 | 「何ヶ月で何ができたか」を共有・比較する文化が育児コミュニティで拡大（Instagramタグ等） |
| 育児エビデンス重視 | 「いつから何ができたか」の記録が小児科受診や健診時の参考情報として活用される |
| 親の自己効力感ニーズ | 子どもの成長を「親の成功体験」として記録・共有することで自己肯定感を高める層が増加 |

### 向かい風となるリスク要因

| リスク | 詳細 | 影響度 |
|--------|------|--------|
| 既存アプリとの競合激化 | 「ぴよログ」「みてね」「成長ノート」など先行アプリがMAU100万超のユーザーベースを持つ | 高 |
| プラットフォーム依存リスク | App Store / Google Playのポリシー変更・手数料（30%）がビジネスモデルに直接影響 | 中 |
| プライバシー・セキュリティ懸念 | 赤ちゃんの写真・動画という極めてセンシティブな情報を扱うため、情報漏洩リスクへの親の警戒が強い | 高 |
| ユーザー継続率（リテンション）の低さ | 育児アプリ全般的に子どもが3歳を過ぎると利用頻度が急落する傾向がある | 中 |
| 出生数の継続的減少 | 国内市場の自然縮小（年間70万人→将来的にさらに減少予測）はTAM縮小を意味する | 中 |
| 無料競合の存在 | 「みてね（MIXI）」のように強力な無料体験を提供する大企業サービスが有料化の障壁になる | 高 |
| 親の時間的余裕の欠如 | 乳幼児育児中の親は慢性的な時間不足で、新しいアプリの学習コストに対して非常に敏感 | 中 |

## 4. 市場参入の機会

### 参入しやすいセグメントと理由

#### セグメント1：初産の親（第一子の親）
- **理由：** 第一子は「初めて」の感動が最も大きく、記録意欲が最も高い。また、既存アプリのユーザーとして定着する前に接触できれば、スイッチングコストゼロで獲得可能
- **特徴：** 産院でのアプリ推薦・マタニティ雑誌・プレパパ・プレママ向け情報メディアを通じたリーチが効果的
- **規模感：** 年間出生数70万人のうち、約40〜45%が第一子（推定28〜32万人/年）

#### セグメント2：育児に積極参加するパパ層
- **理由：** 育休取得率向上に伴い、パパの育児記録参加ニーズが高まっているが、既存の育児アプリはママ向けUIが多く、パパが使いやすいデザインになっていない
- **特徴：** 「パパ向け」「夫婦で共同記録」を前面に出したポジショニングで差別化可能
- **規模感：** 年間育休取得パパ数：約30万人（2024年推計）

#### セグメント3：祖父母とのデジタル接続を求める核家族
- **理由：** 地方在住の祖父母と都市部の核家族をつなぐ「家族共有」機能に対するニーズが高く、かつ祖父母が孫の成長記録を見るために課金する「ギフト課金」モデルが成立しやすい
- **特徴：** 操作がシンプルなシニア向けUIで祖父母ユーザーの参加ハードルを下げることが鍵

---

### 早期に狙うべきニッチ領域

#### ニッチ1：「初めてできた」マイルストーン特化
- **内容：** 「初めて笑った」「初めて歩いた」「初めてしゃべった」という発達マイルストーンに完全特化したデータ構造とUI設計
- **差別化ポイント：** 汎用育児記録アプリとは異なり、「初めての瞬間」だけを記録・保存する体験設計。タイムラインではなく「できたこと図鑑」として整理
- **なぜ今か：** 既存アプリはすべてを記録する汎用型が多く、「初めて」に特化した体験が提供されていない

#### ニッチ2：AIによる「初めて」自動検出
- **内容：** カメラロールの動画・写真をAIが解析し、「これは初めて笑った瞬間では？」「立ち上がっています」と自動候補をサジェスト
- **差別化ポイント：** 忙しい親が「記録する」という能動的行動なしに、AIが「気づき」を届ける。スマートフォンのオンデバイスAI技術（Apple Intelligence等）との連携が実現可能性を高めている
- **なぜ今か：** 2025〜2026年にかけてオンデバイスAI機能が急速に普及しており、技術的実現ハードルが急低下している

#### ニッチ3：産院・小児科との連携による初期ユーザー獲得
- **内容：** 産院・助産院・小児科クリニックとのB2B2C連携により、退院時または健診時にアプリを案内するチャネルを構築
- **差別化ポイント：** 医療機関お墨付きの信頼性をプライバシー懸念の払拭に活用できる。産院への導入費用は低く、ユーザー獲得単価（CAC）を大幅に下げられる
- **なぜ今か：** デジタル母子手帳の普及により、産院・自治体がデジタルツールを推奨する文化が醸成されつつある

#### ニッチ4：海外ルーツ・多言語家族向け
- **内容：** 日本在住の外国人親や、海外に住む祖父母との記録共有を多言語対応で実現
- **差別化ポイント：** 既存の日本語専用アプリが対応できていない海外コミュニティへのリーチ
- **なぜ今か：** 日本の在留外国人数が増加傾向にあり（2025年時点で340万人超）、育児世代も増えている

## まとめ：市場機会の総括

「できた」が参入する成長記録アプリ市場は、少子化による自然縮小リスクを抱えつつも、「1人の子どもへの感情的投資の拡大」「育児のデジタル化加速」「AIによる体験革新」という3つの力学が重なり合い、**質的な拡大フェーズ**にある。

競合が存在する成熟市場ではあるが、「初めてできた瞬間」への感情的共鳴を軸に、**AIによる自動記録提案**と**家族共有のシンプルな体験**を掛け合わせることで、現行アプリが満たしきれていない「継続できる記録体験」というポジションを確立できる可能性がある。

**最重要アクション：** 第一子を持つ産後0〜6ヶ月の親（特にパパ）をアーリーアダプターとして、産院・小児科チャネルを通じたローンチを検討することが最も費用対効果の高い市場参入戦略と考えられる。
