# マーケティング戦略サマリー：赤ちゃん成長記録アプリ「できた」

**作成日：** 2026年4月13日

---

## エグゼクティブサマリー

「できた」は、国内最大手「みてね」が「家族SNS」として横展開している間に生まれた空白地帯——**"初めて"の感動体験に特化した縦深ポジション**を占拠する戦略で市場参入する。ターゲットは25〜35歳の第一子を持つ親（特に育休中ママ）とし、初期90日で産院・助産師経由のオーガニック獲得基盤を構築する。

---

## 1. 戦略の方向性

### 市場における勝ち筋

| 軸 | 内容 |
|----|------|
| **どこで戦うか** | 「みてねが弱い領域」＝初めての瞬間への特化・感動体験・タイムカプセルコンセプト |
| **どう戦うか** | 機能競争ではなく**感情価値競争**。「残す道具」ではなく「子どもへの贈り物を作る体験」として設計 |
| **誰に売るか** | 第一子0〜12ヶ月の育休中ママを最初に攻略し、口コミでパパ・祖父母へ波及させる |

### 優先する成長フェーズ

```
Phase 1（0〜3ヶ月）：認知獲得 → 産院・SNS起点のオーガニック
Phase 2（3〜6ヶ月）：ダウンロード → App Store最適化 + Meta広告
Phase 3（6〜12ヶ月）：継続利用 → プッシュ通知・マイルストーン提案機能
Phase 4（12ヶ月〜）：口コミ・紹介 → 家族招待・SNSシェア機能の強化
```

## 3. 優先チャネルと理由

| 優先度 | チャネル | 根拠 |
|--------|---------|------|
| ★★★ | **産院・助産師連携（オフライン）** | CAC最小・信頼性最高。産後ハイの時期に感情訴求が最も刺さる |
| ★★★ | **Instagram（オーガニック＋広告）** | ターゲット層の主要情報収集チャネル。育児コンテンツの拡散力が高い |
| ★★ | **Apple Search Ads** | 「赤ちゃん 記録」等の高意向キーワードで競合より先にリーチ |

## 4. KPI設計（フェーズ別）

| フェーズ | 指標 | 目標値イメージ |
|---------|------|--------------|
| 認知獲得 | SNSリーチ数・産院設置施設数 | 月間リーチ10万 / 提携産院50施設（3ヶ月目） |
| ダウンロード | CPI・App Store CVR | CPI 300〜500円 / CVR 35%以上 |
| 継続利用 | D30リテンション・月間記録投稿数 | D30リテンション 40%以上 / 月3件以上 |
| 口コミ・紹介 | 家族招待率・SNSシェア率 | 招待率 30% / シェア率 15% |

## 5. 初期90日アクションプラン

### Month 1：基盤構築
- 産院・助産師へのアプローチ開始（10施設でパイロット）
- App Store / Google Play ページ最適化（スクリーンショット・説明文）
- Instagramアカウント開設・コンテンツ10本先行制作

### Month 2：オーガニック拡大
- 産院配布用リーフレット・QRコード設置展開（目標30施設）
- Instagram投稿を週3本ペースで開始（共感系・教育系・口コミ促進系）
- Apple Search Ads 小規模テスト開始（月予算10〜20万円）

### Month 3：有料獲得本格化
- Meta広告テスト開始（月予算20〜30万円・クリエイティブ3パターンABテスト）
- D30リテンションデータをもとにプッシュ通知・マイルストーン提案改善
- 初期ユーザーへのインタビュー実施・口コミ事例の収集・SNS展開
